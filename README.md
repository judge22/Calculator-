# Modern Calculator Application

A sleek, responsive, and fully functional standard calculator web application. This project was built to demonstrate core front-end software development concepts alongside modern **Git & GitHub Workflows** (branching strategies, PRs, and conventional commit standards).
 

---

## 🚀 Live Demo & Features

- **Standard Arithmetic Operations:** Supports Addition (`+`), Subtraction (`-`), Multiplication (`×`), and Division (`÷`).
- **Sequential Evaluation:** Operates like a traditional physical calculator (First Number ➔ Operation ➔ Second Number ➔ Equals).
- **Input Validation & Error Handling:**
  - Prevents multiple decimal points (`.`).
  - Gracefully handles **Division by Zero** with an inline warning (`Cannot divide by 0`).
  - Clears previous error states automatically when entering new numbers.
- **Precision Floating-Point Calculations:** Eliminates JavaScript floating-point representation bugs by rounding dynamically.
- **Modern UI/UX:** Dark-mode glassmorphism styling with hover/active state feedback and clear action buttons (`AC` for clear, `DEL` for backspace).

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom CSS with CSS Grid layout, Flexbox, and modern glassmorphism UI elements.
* **JavaScript (ES6+):** Pure Vanilla JS for DOM manipulation, state management, and calculation logic.
